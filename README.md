# 🧮 ক্যালকুলেটর অ্যাপ্লিকেশন

একটি সম্পূর্ণ কার্যকরী ক্যালকুলেটর অ্যাপ্লিকেশন যা সকল মৌলিক গাণিতিক অপারেশন সাপোর্ট করে।

## ✨ বৈশিষ্ট্য

- ✅ যোগ, বিয়োগ, গুণ এবং ভাগ করার সুবিধা
- ✅ শতাংশ (%) ক্যালকুলেশন
- ✅ দশমিক সংখ্যা সমর্থন
- ✅ ত্রুটি পরিচালনা
- ✅ কীবোর্ড শর্টকাট সাপোর্ট
- ✅ মোবাইল বান্ধব ডিজাইন
- ✅ সুন্দর গ্র্যাডিয়েন্ট ইউআই
- ✅ স্মুথ এনিমেশন এবং ট্রানজিশন

## 🎮 ব্যবহার করার উপায়

### মাউস ব্যবহার করে
1. `index.html` ফাইল খুলুন আপনার ব্রাউজারে
2. সংখ্যা বাটনে ক্লিক করুন
3. অপারেটর বাটন নির্বাচন করুন
4. `=` বাটনে ক্লিক করে ফলাফল পান

### কীবোর্ড শর্টকাট
| শর্টকাট | ফাংশন |
|---------|--------|
| `0-9` | সংখ্যা এন্ট্রি |
| `+` `-` `*` `/` | অপারেটর |
| `.` | দশমিক বিন্দু |
| `Enter` বা `=` | হিসাব করুন |
| `Backspace` | শেষ সংখ্যা মুছুন |
| `Escape` | সব মুছুন (Clear) |
| `%` | শতাংশ |

## 🚀 দ্রুত শুরু করুন

### স্থানীয়ভাবে ব্যবহার করুন
```bash
# শুধু index.html ফাইল খুলুন আপনার ব্রাউজারে
```

### GitHub Pages এ হোস্ট করুন
1. আপনার রিপোজিটরি সেটিংসে যান
2. Pages সেকশন খুলুন
3. Source হিসেবে `main` ব্রাঞ্চ নির্বাচন করুন
4. Save করুন এবং লাইভ ইউআরএল পান
